# Erdős Problem 699 — 2026-09-21 追加進捗

このメモは、2026-09-21 時点で GitHub の `yoshiyoyoyo44/erdos699` を確認したうえで得た追加進捗だけを記録する。
問題699全体、および \(i=3\) 全体の完全解決は主張しない。

## 1. 現在の主対象

GitHub の最新状態では、\(i=3\) の反例候補は

\[
n=2^uM,\qquad u\ge 49,\qquad M>0\ \text{odd},
\]

に正規化されている。固定した混合差 \(D=w-4\lambda\) については

\[
n<18D^2+21
\]

が証明されており、固定 \(D\) は有効に有限化される。
残る主要な領域は、\(D\) や他のパラメータが同時に増大する場合である。

---

## 2. 反例付随三次式の cubic-order 判別式下界

既存稿で

\[
P(z)=\frac{F(z)}{2^vB_{\rm odd}}\in\mathbf Z[z],
\qquad
P(1)=2^{u-v}
\]

が定義されている。ここで \(v=v_2(j)\)。

既に GitHub 上で

- \(P\) は \(\mathbf Q\) 上既約
- 判別式は正
- 3つの根は全て実数

まで証明されている。

したがって、\(P\) を binary cubic form として見たときに対応する cubic order は totally real になる。
判別式は

\[
\boxed{
\operatorname{Disc}(P)
=
\frac{
108j^2(n-j)^2(j-1)(n-j-1)
}{
K^4(n-1)^3(n-2)^2
}
}
\]

となる。ここで

\[
K=2^vM.
\]

totally real cubic field/order の非自明な判別式下界を用いると

\[
\operatorname{Disc}(P)\ge 49
\]

を得るため、既存の判別式評価と合わせて

\[
\boxed{49K^3<2^{u-v+1}}
\]

が反例の必要条件となる。

これは従来の判別式による必要条件を一律に強める。

### 偶数 \(j\)

\(v=v_2(j)\ge1\) のとき

\[
K=2^vM
\]

なので

\[
\boxed{
49\,2^{4v}M^3<2^{u+1}
}
\]

が必要。

従来の

\[
2^{4v}M^3<2^{u+1}
\]

に対する直接の強化である。

### 奇数 \(j\)

既存の

\[
w=\max\{v_2(j-1),v_2(n-j-1)\}\ge2
\]

を使うと、既存の評価

\[
2^wM^3<2^u
\]

に cubic discriminant の下界を組み合わせて強化できる。

小さい totally real cubic discriminant を 2 進付値別に分類する表を使うと、

\[
\boxed{
w\ {\rm odd}
\Longrightarrow
37\,2^wM^3<2^u
}
\]

\[
\boxed{
w\ {\rm even}
\Longrightarrow
71\,2^wM^3<2^u
}
\]

というさらに強い必要条件が得られる候補がある。

この 37, 71 の定数、および下記の 229 の改善は、小判別式 cubic field の表との照合を使うため、独立の証明書・出典確認を付けるまでは「外部分類に依存する強化」として扱う。

---

## 3. \(P\bmod 2\) の形

偶数 \(j\) について、反例付随三次式 \(P\) の mod 2 の形は

\[
v=1:
\qquad
P(z)\equiv z+z^2\pmod2,
\]

\[
v\ge2:
\qquad
P(z)\equiv1+z^3
=(z+1)(z^2+z+1)\pmod2.
\]

となる。

これにより 2 の分解型まで指定でき、totally real cubic field の判別式表と組み合わせれば、単なる

\[
\operatorname{Disc}(P)\ge49
\]

より強い下界が得られる可能性がある。

特に \(v\ge2\) では、外部分類表を使うと

\[
\operatorname{Disc}(P)\ge229
\]

まで上げられる候補がある。

---

## 4. 有理近似不等式の無条件版

GitHub 最新稿では、任意の既約分数 \(0<a/b<1\) に対して

\[
t=bj-an,
\qquad
x=|t|+2b,
\qquad
K_b=K\Lambda(b)
\]

と置くと

\[
K_b(n-1)(n-2)
\le
x^3+\frac34b^2nx
\]

が証明されている。

ここで \(b\le x/2\) を使えば

\[
\frac34b^2nx
\le
\frac{3n}{16}x^3
\]

なので、追加の適用条件なしに

\[
\boxed{
x^3
\ge
\frac{16K_b(n-1)(n-2)}{3n+16}
}
\]

を得る。

反例領域 \(n\ge2^{49}\) では特に

\[
\boxed{
x^3>5K_bn
}
\]

という簡単な形にできる。

この下界は、従来の条件付き評価

\[
x^3>\frac{K_bn^2}{4}
\]

より弱いが、分母 \(b\) の大きさに関する追加条件を必要としない。

## 5. 連分数末尾への適用

\(j/n\) の正規連分数で、最後から一つ前の収束分数を \(a/q\) とする。

この段階では

\[
|qj-an|=1
\]

なので

\[
x=1+2q.
\]

無条件版

\[
x^3>5Kn
\]

を使うと

\[
(1+2q)^3>5Kn.
\]

反例では \(q\) は非常に大きいので、簡単な下界として

\[
\boxed{
q>\frac45(Kn)^{1/3}
}
\]

を得る。

さらに、その一つ前の収束分数の分母を \(c\) とする。

もし GitHub 最新稿の「次の分母上界」が \(c\) に適用できるなら

\[
q^3<
\frac{32n}{K\Lambda(c)}.
\]

一方で上の下界から

\[
q^3>
\frac{64}{125}Kn.
\]

よって両者を合わせると

\[
\frac{64}{125}Kn
<
\frac{32n}{K\Lambda(c)}
\]

なので

\[
\boxed{
K^2\Lambda(c)<\frac{125}{2}
}
\]

が必要になる。

したがって

\[
\boxed{
K\ge8
}
\]

ならこの不等式は不可能。

つまり、\(K\ge8\) の反例が存在するとすれば、最後から二つ前の収束分数 \(c\) は、最新稿の適用条件

\[
4K^2\Lambda(c)^2n\ge27c^6
\]

を必ず破らなければならない。

これは連分数の末尾付近で許される反例候補の構造をかなり限定する新しい必要条件である。

---

## 6. 現時点での位置づけ

今回の追加進捗は主に次の4点。

1. 既約・totally real な反例付随三次式 \(P\) を cubic order として扱い、判別式の絶対下界を導入した。
2. その結果、既存の \(M,u,v,w\) に対する判別式必要条件を定数倍で強化した。
3. GitHub の有理近似不等式から、追加条件を必要としない
   \[
   x^3\ge\frac{16K_b(n-1)(n-2)}{3n+16}
   \]
   を導いた。
4. これを連分数の末尾に適用し、\(K\ge8\) では最後から二つ前の収束分数が既存の「次分母上界」の適用条件を必ず破る、という構造制約を得た。

以上は Erdős Problem 699 または \(i=3\) の完全解決ではない。
