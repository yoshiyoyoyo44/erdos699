1. **新しい橋渡し補題。** \(\Delta=n-2j\) とし、
\[
Q_1=\frac{n-1}{\delta_1}=RS,
\]
ここで \(R\) は \(j\equiv1\)、\(S\) は \(j\equiv0\) を割り当てられた完全素数冪の積とします。まず \(q=p^e\parallel R\) を取り
\[
a=\frac{n-1}{q},\qquad b=\frac{j-1}{q},\qquad
c=\frac{n-j}{q},\qquad d=c-b=\frac{\Delta+1}{q}.
\]
全桁 Kummer より \(b+c=a\) は base \(p\) で無繰り上がりなので
\[
d\in\mathcal D_p(a).
\]
特に \(g_p(a)\) を \(\mathcal D_p(a)\) の最小正要素とすれば
\[
d\ge g_p(a).
\]

ここで三次整数商
\[
\boxed{
C_{R,q}:=
\frac{2\delta_2(j-1)(n-j)(j+n-2)}
{(n-2)q^3}
}
\]
を考えます。これは正整数で、さらに
\[
\boxed{T\mid C_{R,q}}.
\]
実際、\(n-2=aq-1\) であり、既存の第二整除条件を法 \(n-2\) へ移すと
\[
n-2\mid2\delta_2bc(a+b).
\]
一方 \(T\mid n-j\)、かつ
\[
\gcd(T,q(n-2))=1
\]
なので \(T\mid C_{R,q}\) です。

さらに
\[
b=\frac{a-d}{2},\qquad c=\frac{a+d}{2},
\]
だから完全に正確に
\[
\boxed{
C_{R,q}
=
\frac{\delta_2(a^2-d^2)(3a-d)}
{4(n-2)}.
}
\tag{1}
\]
関数
\[
f(d)=(a^2-d^2)(3a-d)
\]
は \(0<d<a\) で狭義減少です。実際
\[
f'(d)=-a^2-6ad+3d^2<0.
\]
したがって全桁条件から
\[
\boxed{
T
\le C_{R,q}
\le
\frac{\delta_2
(a^2-g_p(a)^2)(3a-g_p(a))}
{4(n-2)}.
}
\tag{2}
\]

これが新しい bridge です。**全桁 Kummer の signed-digit gap を、そのまま既存の三次整数商の上下評価へ送っています。**

さらに

\theta_q=\frac{g_p(a)}a

とすれば
\[
\boxed{
q^3\le
\frac{\delta_2(n-1)^3}

(1-\theta_q^2)(3-\theta_q).

\tag{3}
\]
全桁部分を捨てて \(\theta_q\ge0\) だけ使っても、\(R\)-型では

2. **既存の三次式・整数商への適用。** ブロック全体にすると
\[
C_R=
\frac{2\delta_2(j-1)(n-j)(j+n-2)}
{(n-2)R^3}\in T\mathbf Z_{>0},

C_S=
\frac{2\delta_2j(n-j-1)(2n-j-2)}

x_R=\frac{\Delta+1}{n-1}

x_R\in

}
\tag{6}
\]
つまり異なる素数の桁条件を「独立」と仮定する必要はなく、**同じ rational \(x_R\) が全部の signed-digit set に同時所属しなければならない**、という同期条件になります。\(S\) についても

x_S=\frac{\Delta-1}{n-1}

しかも
\[
C_R=
\frac{\delta_2(n-1)^3}

C_S=
\frac{\delta_2(n-1)^3}

したがって full-digit intersection (6) が、三次式の係数へそのまま入ります。

最小 signed gap だけに粗く落とし、

4. **一様上限まで残る具体的障害。** 最も重要なのは、現在までの「桁和・signed gap を大きさへ翻訳する」方法は、多くの場合 **\(n\) を下から押す方向**だという点です。例えば (8) の左辺は

\[
J_q=\frac Mq
\]
と置き、\(p^{K_q}>J_q\) を選びます。\(u\) を全ての
\[
\operatorname{ord}_{p^{K_q}}(2)

\[
2^uJ_q\equiv J_q\pmod{p^{K_q}}.
\]
従って \(j/q=J_q\) の全 base-\(p\) 桁は \(n/q=2^uJ_q\) の対応桁と完全一致し、それより上は0です。よって**全ての \(p\mid T\) で全桁 Kummer を同時通過**します。\(u\) はその公倍数の任意に大きい倍数にできるので

\frac{n-2j\pm1}{n-1}

## 回答 5e71c176-d9de-438a-aef3-77030da07a24

今のところ、**完全有限化まではまだ届いてないけど、ちゃんと一段進んでる**。

一番大きい進展は、前に出した \(Q_1=(n-1)/\delta_1\) 側の全桁 Kummer 条件を、単なる「桁和下界」ではなく、**既存の三次整数商の大きさに直接入れられたこと**。具体的には \(q=p^e\parallel Q_1\) に対して、従来の

\[
q\ll n^{2/3}
\]

から

\[
\boxed{q\ll \frac{n^{2/3}}{T^{1/3}}}
\]

へ強化できた。より正確には枝に応じて

\[
\boxed{
16T^2(n-2)^2q^6
\le 9\delta_2^2(n-1)^6
}
\]

または

\[
\boxed{
27T^2(n-2)^2q^6
\le16\delta_2^2(n-1)^6
}
\]

が出る。\(M\ge5\) では \(T=M/\gamma>1\) なので、これは repo の現行評価より本当に強い。

さらに、各素数を独立だと仮定せず、

\[
x_R=\frac{n-2j+1}{n-1}
\]

という**同じ一個の有理数**が、すべての \(p^e\parallel R\) に対して

\[
x_R\in
\frac1{(n-1)/p^e}
\mathcal D_p\!\left(\frac{n-1}{p^e}\right)
\]

を同時に満たす、という形まで整理できた。\(S\) も同様。これは今までの「各素数で下界を取って足す」よりかなり本質的で、全桁条件の**交差問題**に変わってる。

ただし、ここからすぐ

\[
2^u\le C_0M^{3-\varepsilon}
\]

とはならなかった。理由もかなり明確になった。大きな素数冪 \(q\) で quotient

\[
a=\frac{n-1}{q}
\]

が \(p\) より小さいと、base \(p\) では \(a\) が一桁なので、**上位桁 Kummer が事実上消える**。つまり

\[
\sqrt n \lesssim q\lesssim \frac{n^{2/3}}{T^{1/3}}
\]

あたりに「large-base blind zone」が残る。

しかもこれは架空の問題ではなく、既存の緩和例
\[
(n,j)=(76672,26775)
\]
の \(q=1217\mid n-1\) が実際そうなっていて、その素数では full-digit 条件を全部通る。だから

> 大きな素数冪が一つあれば、その全桁条件だけで強烈な成長矛盾が出る

という補題はそのままでは偽。

逆に smooth 側、小さい素数冪へ細かく分解される場合は、各素数で本当に複数桁を読むので強い。ただ、今は

\[
g_p\!\left(\frac{n-1}{p^e}\right)
\]

という最小 signed deviation が、複数の \(p\) について同時に十分大きくなることをまだ証明できていない。ここが現在の主障害。

だから今の状態を一言で言うと、

\[
\boxed{
\text{「個々の Kummer 条件」}
\to
\text{「実際の素因数分解全体を使う同期条件」}
}
\]

までは進んだ。でも

\[
\boxed{
\text{同期条件}
\to
u=O(\log M)
}
\]

の最後の定量化がまだない。

次に一番狙う価値があるのは、\(Q_1\) と \(Q_2\) を**同時に**使って、同じ中心偏差

\[
\Delta=n-2j
\]

に対する signed-digit intersection を両側から挟むこと。\(Q_1\) だけだと blind zone があるけど、\(n-1\) と \(n-2\) は連続整数なので、両方で同時に blind zone に逃げる素因数構造にはかなり制約があるはず。

現時点では、**「かなり有望な新しい橋はできた。でも逆向き \(M^{3-\varepsilon}\) 評価はまだ未証明」**という状態。
