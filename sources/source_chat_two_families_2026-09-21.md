## 1. 二族での \(\delta_1,\delta_2\)

\[
n=\gamma2^u,\qquad
\gamma=
\begin{cases}
1&n=2^u,\\
3&n=3\cdot2^u.

\[
\boxed{\delta_1=\delta_2=1},
\qquad
Q_1=3\cdot2^u-1,\quad
Q_2=3\cdot2^{u-1}-1,
\]

したがって \(Q_1=2Q_2+1\) です。

\(n=2^u\) では LTE から

\[
\begin{array}{c|cccccc}
u\bmod6&0&1&2&3&4&5\\ \hline
\delta_1&1&1&3&1&3&1\\
\delta_2&1&1&1&3&1&3
\end{array}

となります。従って常に

\[
\boxed{\delta_1Q_1=2\delta_2Q_2+1}.
\tag{1}

ここまでは全指数を完全に覆っています。

引継ぎ条件 \(u\ge51\) により、**両族とも \(u\le50\) は既に排除済み**です。以下は \(u\ge51\) だけ考えます。

## 5. 最小の \(q\) は全合同類で排除できる

(5) と (8) を組み合わせると、各 \(u\bmod6\) で許される最小剰余 \(q=c_0\) は排除できます。

例えば \(\delta_1=\delta_2=1,\gamma=1\) で \(q=1\) なら

\[
xy=2^{u-1}-1,\qquad x+y=2^{u-2v-1}.
\]

\(v\ge1\) のとき

\[
(x-1)(y-1)
=2^{u-2v-1}(2^{2v}-1),
\]
\[
(x+1)(y+1)
=2^{u-2v-1}(2^{2v}+1).
\]

両者の \(2\)-進付値が同じなので、一方を \(x\equiv-1\)、他方を \(y\equiv1\) とすると必然的に

\[
x=2^{K-1}-1,\qquad
y=2^{K-1}+1,\qquad K=u-2v-1.
\]

従って

\[
u-1=2K-2,
\]

すなわち

\[
u=4v+3,
\]

となり \(g=u-4v=3\)。これは \(g\ge14\) と矛盾します。\(v=0\) では一方の因子が \(1\) となり、反例のブロック条件に反します。

同じ議論で、\(\delta_2=3\) の \(q=3\) は \(3Q=2^{u-1}-1\) に吸収され、\(\delta_1=3\) の \(q=9\) は \(x,y\) がともに \(3\) の倍数となるので \(3\) で割って同じ問題になります。\(n=3\cdot2^u\) の \(q=1\) も同じ \(2\)-進因子分解で排除できます。

したがって

\[
\boxed{
q\ge
\begin{cases}
17,&c_0=1,\\
19,&c_0=3,\\
25,&c_0=9.
\end{cases}}
\tag{10}
\]

これは全ての \(u\ge51\)、奇数・偶数 \(j\) を覆います。

## 6. さらに \(q\) に指数依存の下界

## 7. 全桁 Kummer 条件を残存系にどう入れるか

ここは重要です。低位の

\[
Q_1\mid j(j-1),\qquad Q_2\mid j(j-1)(j-2)
\]

だけで終わらせてはいけません。

完全素数冪 \(p^e\Vert Q_1\) に対し
\(\epsilon=j\bmod p^e\in\{0,1\}\) とすると、全桁 carry-free は正確に

\[
\boxed{
p\nmid
\binom{(n-1)/p^e}{(j-\epsilon)/p^e}.
}
\tag{14}
\]

同様に \(p^e\Vert Q_2\) で
\(\eta=j\bmod p^e\in\{0,1,2\}\) なら

\[
\boxed{
p\nmid
\binom{(n-2)/p^e}{(j-\eta)/p^e}.
}
\tag{15}
\]

です。これは下 \(e\) 桁を取り除いた後も、残りの全桁で carry が無いことそのものです。

今回、(14),(15) を (6)–(13) に重ねましたが、**全ての \(p^e\) に同時に適用して \(q\) を (13) より本質的に小さくする一様評価**までは得られませんでした。既知の桁和評価も、\(T=1\) では \(s_p(n)\) や桁次数が \(p,u\) とともに動くため、その穴をまだ埋めません。
