# i=3：全素因数をまとめる桁和評価と、任意次数の因子分配

[入口](../../README.md) · [現在地](../../docs/STATUS.md) · [直前の続稿](i3_multiplicity_budget_and_fresh_support_2026-09-23.md)

2026-09-23。基準コミット `a246167`。**一般枝は未解決である。** 本稿は、全桁 Kummer 条件からの制限を、素数ごとの式から全素因数を含む式へ進める。第1–3節は j の偶奇、T、指数差 G に制限を置かない。

**続報：** [四次の完全分類](i3_quartic_digit_classification_2026-09-23.md)で、本稿に残した2+2分配を二族へ分類し、整数値で両族を2進排除した。任意次数での最高次係数比の公式も追加した。以下は本稿時点の記録を保存する。

主な結果は次の二つ。

1. $Q_1=(n-1)/\delta_1$、$M_1=\Omega(Q_1)$（重複込みの素因数の個数）、$H_1=\max_{p\mid Q_1}s_p(n)$ とすると、反例には

   $$n<16\cdot7^{M_1}(H_1+2)^{2M_1^2+4M_1}$$

   が必要。M₁ が有界なら H₁ は n の正の冪以上になる。H₁ が log n の固定冪以下なら、M₁ は少なくとも $\sqrt{\log n/\log\log n}$ 程度に増える。
2. 非自明な桁多項式が二つの整除条件を満たす場合、F−1 の因子を J と J−1 に分ける両側の次数は m/3 以上。F−2 を J、J−1、J−2 に分ける各側の次数は m/2 以下。四次では F−1 の 1+3 分配が不可能となり、2+2 分配だけが残る。

これらは有限範囲の探索結果ではなく、以下の一般証明による。楕円曲線の表や新しい外部定理は使わない。

## 1. 素数ごとの上界から次数を消す

i=3 の反例を仮定する。既存の初等的還元から $n\ge8$、$4\mid n$、$4\le j\le n/2$。
$\delta_1=3$ if $v_3(n-1)=1$、それ以外は1とし、$Q_1=(n-1)/\delta_1$ と置く。

p≥5 が Q₁ を割るとき、n と j の p 進桁多項式を F,J とすれば、Kummer 条件より

$$F(0)=1,\qquad 0\le [X^r]J\le[X^r]F.$$

[二つの法と桁の高さ・第4–7節](i3_cross_modulus_and_digit_height_2026-09-20.md)により、m=deg F、H=sₚ(n) として

$$p\le6H(H+1)(H+2)^{2m+2}+2\le7(H+2)^{2m+4}. \tag{1}$$

この入力の要点は次の通り。右の閾値を超える p では、数値の $n-2\mid6j(j-1)(j-2)$ を整数の疑似除算により $F-2\mid J(J-1)(J-2)$ へ移せる。F(x)=2 となる正実数 x で非負係数を使うと、J は 0,1,F−1,F のいずれかとなり、j の範囲に反する。素数3が Q₁ に残る場合にも、(1)の最後の上界自体は自明に成り立つ。

以下 log は自然対数。$L=\log n$、$y=\log p$、$a=\log(H+2)$、$b=\log7+4a$ と置く。
$p^m\le n$ なので m≤L/y。(1)から

$$\boxed{y^2\le by+2La.} \tag{2}$$

従って

$$\boxed{\log p\le\frac{b+\sqrt{b^2+8La}}2
\le b+\sqrt{2La}.} \tag{3}$$

これは次数 m が動く場合にも有効な明示式である。p≥5 の Q₁ 側には無条件に適用できる。Q₂ 側については第5節の適用条件が必要であり、全ての p に無条件に使ってはいけない。

## 2. Q₁ の全素数冪を同時に数える

$$Q_1=\prod_{p\mid Q_1}p^{e_p},\qquad
M_1=\sum e_p,\qquad H_1=\max_{p\mid Q_1}s_p(n),\qquad
a=\log(H_1+2),\quad b=\log7+4a.$$

Q₁>1 なので M₁≥1。各 p で(2)を同じ a,b に弱め、eₚ を掛けて足すと

$$\sum e_p(\log p)^2\le b\log Q_1+2LaM_1.$$

Cauchy の不等式を使い、$\ell=\log Q_1$ とすると

$$\boxed{\ell^2\le M_1b\ell+2LaM_1^2.} \tag{4}$$

**定理1。** 全ての i=3 の反例には

$$\boxed{n<16\cdot7^{M_1}(H_1+2)^{2M_1^2+4M_1}} \tag{5}$$

が必要である。

**証明。** $d=L-\ell=\log(\delta_1 n/(n-1))$ とする。n≥8、δ₁≤3 より 0<d<log4。
$C=2aM_1^2+bM_1$ と置けば、(4)は

$$f(\ell):=\ell^2-C\ell-2aM_1^2d\le0.$$

一方

$$f(C+d)=d(M_1b+d)>0,$$

かつ f は [C+d,∞) で単調増加。従って ℓ<C+d、L=ℓ+d<C+2d<C+log16。
C を展開して指数を取ると(5)になる。□

固定した上限 M₁≤M、H₁≤H に対しても、右辺を M,H で置き換えた計算可能な n の上限が得られる。素数自体を固定する必要はない。

### 2.1. 少数の素数冪に対する桁和の強制

(5)を逆に読むと

$$\boxed{H_1+2>
\left(\frac{n}{16\cdot7^{M_1}}\right)^{1/(2M_1^2+4M_1)}.} \tag{6}$$

例えば M₁=2,3,4 に対応する n の指数は、それぞれ 1/16,1/30,1/48。
ここでの M₁ は**異なる素数の個数ではない**。たとえば Q₁=p¹⁰q なら M₁=11 である。

$p^{e_p}\Vert n-1$ と書けば、$s_p(n)=1+s_p((n-1)/p^{e_p})$。
従って(6)は、9月22日の記録で用いた shifted digit sum の少なくとも一つに対する下界でもある。

### 2.2. 小さい桁和を保つなら重複込みの素因数が増える

仮想反例列で L→∞、固定 c>0 に対して H₁≤Lᶜ とする。(5)の対数を取り、a≤c log L+o(1) を代入すると

$$\boxed{M_1\ge(1-o(1))\sqrt{\frac{L}{2c\log L}}.} \tag{7}$$

実際、M₁ がこの下界より固定比率だけ小さければ、主項 2aM₁² が L より固定比率だけ小さくなり、4aM₁、M₁ log7、log16 は o(L) なので矛盾する。

偶数枝の $G=(1+o(1))\log_2u$ では、[直前の続稿](i3_multiplicity_budget_and_fresh_support_2026-09-23.md)より T=uᵒ⁽¹⁾、従って L∼u log2。H₁≤uᶜ なら

$$M_1\ge(1-o(1))\sqrt{\frac{u\log2}{2c\log u}}. \tag{8}$$

$e_{\max}=\max e_p$ とすると M₁≤eₘₐₓω(Q₁) だから、同じ下界を $e_{\max}\omega(Q_1)$ にも適用できる。ω(Q₁) だけの下界へ置き換えるには、eₘₐₓ の上界が別に必要である。

## 3. 桁和が素数ごとに違う場合の式

$a_p=\log(s_p(n)+2)$、$y_p=\log p$ とすれば、最大値 H₁ にまとめる前の(4)は

$$\boxed{\frac{\ell^2}{M_1}\le
(\log7)\ell+4\sum e_pa_py_p+2L\sum e_pa_p.} \tag{9}$$

これは一つの大きい桁和が全ての素数の上界を緩めるのを避ける。例えば yₚ≤L、ℓ<L より

$$\boxed{\sum e_p\log(s_p(n)+2)>
\frac{(L-\log4)^2}{6LM_1}-\frac{\log7}{6}.} \tag{10}$$

右辺が負ならこの弱めた形は情報を与えない。(9)自体を使えば、個別の高さと完全素数冪の指数を保ったまま候補を検査できる。

## 4. 任意次数の桁多項式に対する因子の次数制限

以下は独立した Q[X] 上の補題である。m=deg F≥1、F(0)=2、F,J は非負係数で係数ごとに 0≤J≤F、かつ

$$F-1\mid J(J-1),\qquad F-2\mid J(J-1)(J-2). \tag{11}$$

J∉{0,1,F−1,F} とする。

**定理2。** F−1 の各既約因子は、その重複度を全部含めて J または J−1 の片方へ入る。$F-1=UV$、$U\mid J$、$V\mid J-1$ と分配したとき

$$\boxed{m/3\le\deg U,\deg V\le2m/3.} \tag{12}$$

F−2 を J−s（s=0,1,2）へ同様に分配した因子を Dₛ とすると

$$\boxed{\deg D_s\le m/2\quad(s=0,1,2).} \tag{13}$$

**証明（F−1 側）。** J と J−1 は互いに素なので、分配は重複度も含めて行える。定数項1に正規化して UV=F−1 とする。
J=1+VL と書けば deg L≤deg U。法 F−2 では UV≡1 だから

$$UJ\equiv U+L,$$

$$F-2\mid (L+U)L(L-U). \tag{14}$$

右辺が零多項式なら L=0,U,−U のいずれかで、J=1,F,2−F。最後の形は非定数の係数が負になり、前二つは自明な形なので、どれも仮定に反する。
従って m≤3 deg U。J を F−J に換えても二つの整除条件と係数条件は保存され、U,V の役割が入れ替わる。従って m≤3 deg V も得る。deg U+deg V=m なので(12)となる。

**証明（F−2 側）。** D=Dₛ、$F-2=DE$、$J-s=DK$ と書く。deg E=m−deg D、deg K≤deg E。
法 F−1 で DE≡−1 だから

$$EJ\equiv sE-K,$$

$$F-1\mid(sE-K)((s-1)E-K). \tag{15}$$

右辺が零なら $J=s(F-1)$ または $J=(s-1)F+2-s$。
s=0,1,2 を代入すると 0,1,F−1,F、または係数条件に反する 2−F,2F−2 だけである。
従って m≤2 deg E=2(m−deg D)、すなわち(13)を得る。□

**重複した既約因子の冪を途中で分割してはいけない。** (12),(13)の検査単位は、既約多項式 f そのものではなく、F−1 または F−2 に現れる完全な冪 fᵉ の次数である。

### 次数4以上で残る分配

| m | F−1 の分配（順序を除く） | F−2 の分配（順序を除く） |
|---|---|---|
| 4 | (2,2) | (2,2,0), (2,1,1) |
| 5 | (3,2) | (2,2,1) |
| 6 | (4,2), (3,3) | (3,3,0), (3,2,1), (2,2,2) |

特に四次の 1+3 分配は全係数について排除された。ただし四次全体の分類ではない。
例えば任意の非負整数係数 K(X)（K(0)=0、deg K=2）に対し

$$F=12K^2+8K+2,\qquad J=6K^2+K \tag{16}$$

は非自明な四次の解であり、F−1=(6K+1)(2K+1) は 2+2 分配になる。
この族は F(x)≡2 mod4 のため本来の反例ではないが、(11)だけから全ての四次多項式を排除することはできない。

(16)は(13)の m/2 に等号が生じる例でもある。また[三次の非自明な族](i3_cubic_digit_classification_2026-09-20.md)に K を合成すると、F−1 の次数分配は (m/3,2m/3) となる。従って、これらの定数を(11)と係数条件だけで一律に改善することはできない。本来の反例を除くには、整数値での付値や商の分母などを追加する必要がある。

## 5. Q₂ 側の素数上界を新しい配置へ広げる

p≥5 が Q₂=(n−2)/(2δ₂) を割るとし、F を n の p 進桁多項式とする。F(0)=2。
第4節により、次のいずれかの場合は非自明な(11)の解がなく、(1)–(3)を適用できる。

1. F−1 の完全な既約因子冪の次数を、両側とも [m/3,2m/3] に入る二群へ分配できない。
2. F−2 の完全な既約因子冪のどれかが次数 m/2 を超える。
3. より一般に、F−2 のそれらの次数を、各々 m/2 以下の三群へ分配できない。

特に F−1 に次数 >2m/3 の既約因子冪がある場合、または $v_X(F-2)>m/2$ の場合は上界が成り立つ。
従来の「F−1 が一種類の既約因子の冪」の条件を、複数の既約因子がある場合へ広げている。
三次までの全分類と、非零桁の位置の2進付値が揃う場合の既存の判定も引き続き使える。

例えば $F=4X^4+4X^3+3X^2+3X+2$ では

$$F-1=(2X+1)(2X^3+X^2+X+1),\qquad F-2=X(X+1)(4X^2+3).$$

前者の三次式は有理根を持たず既約なので 1+3 分配が強制され、第一の判定で除ける。後者は三群への分配が可能であり、こちらの次数判定だけでは除けない。逆に $F=2+4X^3+3X^4$ では F−1 は完全な因子冪の次数2+2に分かれるが、F−2 の X³ により第二の判定で除ける。

これらの判定を通らない p に同じ上界を断定してはいけない。二つの均衡した分配が可能というだけでは、(11)の解が存在するともいえない。

## 6. 一般枝を閉じるには何が不足するか

第2節は Q₁ の全素因数を扱い、奇数 j にも適用できる。しかし、H₁ と Ω(Q₁) の両方が増えることを禁じていない。特に次が残る。

* 小さい桁和を保ちながら Ω(Q₁) を増やす配置。重複度が増える場合と、異なる素数が増える場合の両方を含む。
* Ω(Q₁) が小さく、一つ以上の sₚ(n) が n の正の冪となる配置。
* Q₂ 側で m≥4、かつ第4節の因子分配を満たす桁多項式。

また、仮に必要な全素数へ(3)を適用できても、直前の稿で得た F_K の下界とそのまま比べるだけでは、矛盾にはならない。
G∼log₂u、L∼u の領域では、前者の対数は log u 程度でよい一方、H が有界でも後者は √u 程度の log p を許す。したがって「素数の積の下界」と「個々の素数の上界」を得ただけで一般枝が閉じたとはいえない。

次の課題は、(9)の大きい桁和が各ブロックの商・付値へ与える制限を導くこと、または残った Q₂ の均衡分配を、整数の商の分母と2進・3進条件まで保って分類することである。今回は四次の完全分類や任意次数の排除は主張しない。
