# i=3：任意次数の桁和降下と、全奇素数の付値保存

[入口](../../README.md) · [現在地](../../docs/STATUS.md) · [四次分類と一般の係数比](i3_quartic_digit_classification_2026-09-23.md)

2026-09-23。基準コミット `b8cffad485e97ca9cec237ace3d8a3e4d1844e60`。
**一般枝は未解決である。** 本稿は次数別の分類を進めず、桁和へ縮小したときに、全ての関連する奇素数の条件を同時に保存する十分条件を証明する。

主な結果は、基数 b=pᵈ で

$$H=s_b(n),\qquad A=s_b(j),\qquad
D_b=\gcd(n-H,j-A)$$

としたとき、下で定義する明示的な整数 M(H) が D_b を割れば、仮想反例から小さい反例への**正しい降下**が得られることである。次数の上限や、素数が係数からの閾値を超えるという仮定は不要。

ただし、適切な p,d が必ず存在することは未証明である。この存在命題を降下そのものの証明と分ける。

出発点は[既存の桁和から別の素数への移行補題・第4節](i3_global_digit_constraints_2026-09-19.md)である。本稿では全奇素数の付値を一度に扱い、基数の合同式を実際の差の合同式へ緩め、添字の範囲まで確認した条件付き降下としてまとめる。文献上の新規性は主張しない。

## 1. 小さい行の全奇素数を同時に扱う法

H≥4 に対し

$$\mathcal P(H)=\left\{q\text{：奇素数},\ q\mid\binom H3\right\},
\qquad K_q(H)=\lfloor\log_q H\rfloor,$$

$$\boxed{M(H)=8\prod_{q\in\mathcal P(H)}q^{K_q(H)}.} \tag{1}$$

空積は1とする。H≥8 なら M(H) は lcm(1,2,…,H) の約数である。
この法は j に依存せず、行 H の全ての添字を同時に扱う。素因数分解が必要なのは H(H−1)(H−2)/6 であり、大きい n の二項係数を展開する必要はない。

以下、zₒdd は正整数 z の奇数部分を表す。

**定理1（付値の移行）。** n≥3、0≤j≤n、H≥4、0≤A≤H に対し

$$n\equiv H\pmod{M(H)},\qquad j\equiv A\pmod{M(H)} \tag{2}$$

なら

$$\boxed{
\gcd\!\left(\binom H3,\binom HA\right)_{\rm odd}
\mid
\gcd\!\left(\binom n3,\binom nj\right)_{\rm odd}.} \tag{3}$$

より強く、q∈P(H) の各素数について

$$v_q\binom n3\ge v_q\binom H3,\qquad
v_q\binom nj\ge v_q\binom HA. \tag{4}$$

**証明。** K=K_q(H) とする。Kummer の公式は

$$v_q\binom HA=
\sum_{k\ge1}\mathbf1_{\{A\bmod q^k>H\bmod q^k\}}. \tag{5}$$

qᵏ>H なら H mod qᵏ=H≥A=A mod qᵏ なので、k>K の項は0。
k≤K の各項は(2)により n,j 側でも同じ値になる。n,j 側のそれより上の項は非負だから、第二の不等式が従う。これは一つの繰り上がりだけでなく、共有する素数冪の指数も保存する。

第一の不等式については、H,H−1,H−2 のうち q の倍数となるものは一つだけである。その付値は、正で H 以下の整数の付値なので K 以下。(2)は対応する n,n−1,n−2 の付値をそれ以上に保つ。分母6の付値を引けばよい。
q=3 が P(H) に入るときは H(H−1)(H−2) の3進付値が2以上なので、K≥2 であり、必要な法9を失っていない。各 q で最小値を取れば(3)が得られる。□

この定理自体には、n,j の反例仮定も桁多項式の整除条件も要らない。

## 2. 桁和を取る前後の範囲

p は奇素数、p|binom(n,3)、p∤binom(n,j) とする。
Kummer により j+(n−j)=n は p 進で繰り上がりがない。
任意の d≥1 で d 桁ずつまとめても繰り上がりはない。b=pᵈ として

$$H=s_b(n),\quad A=s_b(j),\quad B=s_b(n-j)$$

と置くと

$$\boxed{H=A+B.} \tag{6}$$

b≤n なら n には上位の非零桁があるので H<n。
j と n−j がともに p の冪でなければ、A,B≥2 も従う。桁和1の正整数は b の冪、従って p の冪だからである。

既存の反例の六ブロック還元では

$$j=TSBg,\qquad n-j=TRCh,$$

S,B は互いに素でどちらも1より大きく、R,C も同様である。
従って、j と n−j はどの素数についても純粋な素数冪ではない。
この既存入力は[六ブロックと全桁条件](i3_global_digit_constraints_2026-09-19.md)による。
この節の B=s_b(n−j) は、引用元の因子ブロック B とは別の記号である。

## 3. 反例を反例へ移す条件付き降下

**定理2（任意次数の降下）。** i=3 の反例 n,j が存在し、既存の正規化 8|n および前節の非素数冪条件を満たすとする。
奇素数 p|binom(n,3) と 1≤d≤⌊logₚn⌋ を選び、b=pᵈ、H,A を前節のように定める。
もし

$$\boxed{M(H)\mid D_b:=\gcd(n-H,j-A)} \tag{7}$$

なら

$$\boxed{\left(H,\min(A,H-A)\right)} \tag{8}$$

は元の反例より小さい i=3 の反例である。

**証明。** 前節から H<n、A,H−A≥2。(7)と8|n より8|H、従ってH≥8。
元の反例では(3)の右辺が1なので、左辺も1である。

a=min(A,H−A) とする。a=2 または3 は不可能。
実際、H−1≡7 mod8 なので H−1 は3の冪ではなく、素因数 q≥5 を持つ。
この q は binom(H,3) と binom(H,2) の双方を割り、a=3 でも共通素因数になる。
従って4≤a≤H/2。binom(H,A)=binom(H,a) だから、共有する奇素因数がないという条件を保った、正しい範囲の小さい反例を得る。□

既存の u≥51 により反例の8|nは満たされる。本稿は u≥51 の証明書を再証明するものではない。

**系2.1（既存の2進下界を降下先へ戻す）。** 最小性を仮定しない一般の反例でも、(7)が成立するなら

$$\boxed{2^{51}\mid H.} \tag{8a}$$

実際、定理2で得た組は i=3 の反例そのものなので、既存の全反例に対する u≥51 を再び適用できる。
従って、H<2⁵¹、あるいは H が2⁵¹で割り切れない圧縮については、(7)の成立だけで即座に矛盾する。
これは行Hを全列挙した主張ではなく、[既存の2進下界と有限証明書](i3_cubic_discriminant_minima_2026-09-21.md)への帰結である。

### 最小反例への帰結

**系2.2。** n を最小とする反例があれば、その全ての奇素数 p|binom(n,3) と全ての許される d に対して

$$\boxed{M(s_{p^d}(n))\nmid
\gcd\bigl(n-s_{p^d}(n),\ j-s_{p^d}(j)\bigr).} \tag{9}$$

これは有限個の桁和だけを調べた命題ではない。任意の桁和・次数について、より小さい反例を排除する最小性から従う。
小さい行の i=3 を無条件に解決済みと仮定した議論でもない。

## 4. 基数そのものの合同式は、簡単な十分条件

どの正整数 z に対しても z≡s_b(z) mod(b−1)。従って

$$\boxed{M(H)\mid b-1\quad\Longrightarrow\quad M(H)\mid D_b.} \tag{10}$$

最小反例では、全ての候補 b=pᵈ で M(H)∤b−1 が必要になる。
特に h≥8 で lcm(1,…,h)|(p−1) なら

$$\boxed{s_p(n)>h} \tag{11}$$

が必要。もし H≤h なら、p≡1 mod8 と8|nにより H は8の倍数であり、H≥8。
さらに M(H)|lcm(1,…,h)|(p−1) となって(9)に反するからである。

これは桁和の任意の閾値 h に対する命題である。ただし適用対象は**最小反例**であり、既存の有限 lifting 証明書が与える「全反例の必要条件」と同じ主張ではない。
一般の反例に(10)を課すと、まず定理2の小さい反例への降下を得る。
系2.1の範囲では一般の反例も直ちに排除できる。

### 実際の差を使う条件の方が広い

(7)は(10)を仮定しない。例として、b=11、

$$J_0=1+11^2+2\cdot11^4=29404,$$

$$n_m=J_0(1+11^{6m}),\qquad j_m=J_0,\qquad m\ge1 \tag{12}$$

を考える。二つの桁群は重ならず、全桁で jₘ≤nₘ。H=8、A=4、M(8)=56 である。
J₀≡4 mod56、11⁶≡1 mod56 より、(7)は全mで成立するが、56∤11−1 なので(10)は成立しない。

この族では7が binom(8,3) と binom(8,4) の共通因数であり、定理1により元の二項係数にも7が現れる。
従って、この族は反例ではない。次数6m+4が任意に大きく、基数11が小さい場合でも、実際の差からの移行が働く例である。反例の他の正規化まで満たす族とは主張しない。

## 5. 一つの小さい法だけで排除できる場合

M(H)全体の整除性は、全ての関連素数を同時に保存する十分条件である。
実際の排除では、共有素数の一つだけを移せばよい。

qが binom(H,3) と binom(H,A) を共に割るとする。
(5)で最初に1となる指数を k とし、

$$e=\max\bigl(k,\ 2\text{ if }q=3\text{ else }1\bigr).$$

このとき qᵉ≤H。q=3 では q|binom(H,3) から H≥9、他の素数では k≤K_q(H) を使う。
従って

$$\boxed{q^e\mid\gcd(n-H,j-A)
\quad\Longrightarrow\quad
q\mid\gcd\!\left(\binom n3,\binom nj\right).} \tag{13}$$

この局所証明書は、法 qᵉ、二つの剰余、最初の carry の位置だけで再検算できる。
桁和が1000以下などの固定した範囲に制限する必要はない。

最小反例では、各圧縮で a=min(A,H−A)≥4 なら、行Hに少なくとも一つの共通奇素数がある。
従って、そこから得る(13)の全ての証明書が元の n,j への移行に失敗しなければならない。
この「全基数・全ブロック長での失敗」を同時に排除することが、残る存在命題の一つの形である。

## 6. 強い十分条件の限界も定量化する

8|H の場合

$$v_2\binom H3=v_2(H),\qquad
\left(\binom H3\right)_{\rm odd}=\frac{H_{\rm odd}(H-1)(H-2)}6.$$

各 q について v_q binom(H,3)≤K_q(H) なので

$$\boxed{M(H)\ge\frac43H_{\rm odd}(H-1)(H-2).} \tag{14}$$

H≥16 では右辺は H² より大きい。よって、**(10)を使う場合**は H<√b が必要。
H=8 でも、M(8)=56、b≡1 mod56 の最小の b>1 は57だが、57は素数冪ではない。従って基数が素数冪なら b≥113>8² で、同じ結論を得る。

系2.1と合わせると、一般の反例で(10)が成立する場合には H≥2⁵¹、従って b>2¹⁰² が必要になる。これも最小性を仮定しない条件付きの必要条件である。

特に b=pᵈ とし、nのp進桁をfᵢとすると

$$s_{p^d}(n)=\sum_{r=0}^{d-1}p^r\sum_{k\ge0}f_{kd+r}.$$

H<p^(d/2) より、r≥⌈d/2⌉となる位置の桁は全て0でなければならない。
たとえば d=2 の(10)には、奇数番目のp進桁が全て0という強い疎性が必要になる。

これは(10)が自動的に成立しそうだという期待への制限である。
**実際の差を使う(7)には、このH<√bという結論を適用していない。** (12)はH=8>√11であり、その違いを明示する。

## 7. 何が進み、何がまだ必要か

従来の[二次式による降下候補](i3_descent_kummer_obstruction_2026-09-20.md)では、新しい分母の整数性と上位桁の保存が未証明だった。本稿の(7)の下では、縮小後の整数・添字の範囲・全関連奇素数の付値をまとめて扱える。
各次数の分類や、桁多項式への移行閾値を使わない点が今回の方向転換である。

しかし、(7)を満たす基数が全反例で必ず見つかることは証明していない。
特に、(9)を全p,dで満たし、全ての局所証明書(13)も失敗する配置を除く必要がある。
反例から小さい反例への**条件付き降下の正しさ**と、その降下を**必ず適用できること**は別の命題である。

次に狙う十分な被覆命題は、最小反例の六ブロック条件と既存の大きさの評価から、あるp,dで(7)または(13)を強制することである。この被覆が証明されれば最小反例が存在しないと結論できる。現時点では未証明である。
